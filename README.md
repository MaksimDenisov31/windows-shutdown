# Выключение Windows

## Скачать

**[Скачать WindowsShutdown.exe](https://github.com/MaksimDenisov31/windows-shutdown/releases/latest/download/WindowsShutdown.exe)**

Ссылка скачивает только готовый EXE. Скачивать весь проект и устанавливать программу не нужно. Сохраните файл и запускайте при необходимости выключить компьютер через 30 секунд.

Отдельный EXE со встроенным красным значком питания. При запуске вызывает системную команду:

```text
shutdown.exe -s -t 30 -c "Компьютер выключится через 30 секунд"
```

Поведение соответствует исходному BAT: выключение через 30 секунд, без принудительного закрытия приложений. Дополнительного подтверждения перед выключением нет. Для отмены запланированного выключения можно выполнить `shutdown /a`.

Готовый файл: `dist/Выключение Windows.exe`. Его можно переносить отдельно, BAT и файл значка рядом не нужны. Требуется штатный .NET Framework 4.x в Windows.

Исходный BAT сохранён в `original/`. Программа не зависит от этой копии.

## Сборка

В Windows PowerShell:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Build.ps1
```

Сборка создаёт значок и компилирует приложение штатным компилятором .NET Framework. Она не запускает приложение и не выполняет команду выключения.

При подготовке проекта EXE и BAT не запускались по просьбе пользователя.
